# Nexus Co-Living Spaces — Website Software Solution

A complete responsive static website for the Nexus Co-Living Spaces BTEC website-development project.

## Included
- 6 responsive HTML pages: Home, About, Packages, Facilities, FAQ, Contact
- Shared responsive CSS stylesheet
- JavaScript for mobile navigation, FAQ accordion, form validation and dynamic footer year
- Local image assets in SVG format
- Generated Nexus visual showcase image (`images/nexus-showcase.png`)
- Accessibility features: semantic structure, labels, skip link, focus states, ARIA attributes and reduced-motion support

## Run
Open `index.html` in a modern browser. No server is required.

## Contact form
The form performs client-side validation and displays a demo success message. For a production deployment, connect it to a backend, email API or form service.
